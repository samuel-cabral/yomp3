# Changelog

All notable changes to YoMP3 are documented here. Format inspired by [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.2.0] — unreleased

### Added
- App icon (placeholder)
- Hardened runtime entitlements
- `VERSION` file and plist injection
- Developer ID signing + notarization hooks in build/package scripts
- Multi-URL paste and drag&drop in URL input
- "Abrir pasta" toolbar action and actionable empty state in download list
- `os.Logger` foundation
- Forward-compatible `DownloadItem.Status` Codable
- README troubleshooting section and download placeholder

### Changed
- Build script reads version from `VERSION`

## [0.1.0] — 2026-05-09

### Added
- Initial MVP: URL input, queue, downloader, playlist resolver, settings, scripts, README.
